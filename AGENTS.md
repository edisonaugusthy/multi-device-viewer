# Project agent instructions

## Private project documentation

For project changes, find the private requirements through the authorized
workspace connection. Search by repository name and verify the repository match.
Read the relevant requirements before building and update the affected entries
after validation. Use this lookup to resolve the documentation home when running
`/deliver`.

Keep private page URLs, IDs, titles, excerpts, and internal details in the
private workspace. Omit them from repository files, commits, pull requests,
release materials, and reports. Report documentation sync status without page
links or details. Read-only questions need no documentation update.
