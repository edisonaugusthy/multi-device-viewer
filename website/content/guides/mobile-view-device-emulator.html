Open mobile view with Chrome DevTools

  1. Open the page in desktop Chrome, right-click it, and select Inspect.
  2. Click Toggle device toolbar in DevTools. The shortcut is Ctrl + Shift + M on Windows and Linux or ⌘ + Shift + M on Mac.
  3. Choose a phone preset, or select Responsive and enter an exact width such as 390 CSS pixels.
  4. Reload if the site chooses its layout on page load. Click the device toolbar button again to return to the desktop layout.

See the Chrome Device Mode documentation for orientation, touch input, and throttling options.

Compare mobile and desktop layouts side by side

  1. Open the website you want to test in Chrome.
  2. Open Mobile View from the toolbar or page context menu.
  3. Start with a compact phone and a laptop, then add a tablet or the exact viewport reported by your analytics.
  4. Check navigation, forms, sticky UI, text wrapping, images, and horizontal overflow at each width.
  5. Capture and annotate a failure, or copy a structured fix prompt for your coding assistant.

Why a phone-sized window can show a different page

Responsive layouts usually change at CSS breakpoints on the same URL. Some servers also check the browser identity before sending a page or redirect to a separate mobile URL. If the phone preview looks different from a physical phone, compare the final URL and reload in Device Mode with a phone preset selected.

Use a physical phone to verify its browser engine, camera, software keyboard, and touch behavior. An iPhone frame in desktop Chrome still uses Chrome’s desktop browser engine.
