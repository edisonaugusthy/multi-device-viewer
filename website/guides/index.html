A practical order for responsive testing

  1. Start with a compact phone, large phone, tablet, and laptop viewport.
  2. Exercise the same navigation and content state across those widths.
  3. Check immediately around real CSS breakpoints with custom viewports.
  4. Capture the failure with the viewport, expected result, and actual result.
  5. Verify critical journeys in target browsers and on physical devices.
