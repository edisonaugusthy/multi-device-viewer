常见问题。

免费吗？+

是的。基于 MIT 许可证免费开源，无需账号。

支持 localhost 吗？+

支持。在 Chrome 中打开本地页面，再打开 Mobile View 即可。任何内容都不会离开你的电脑。

和 DevTools 的设备模式有什么不同？+

DevTools 一次只显示一个视口。Mobile View 并排显示四台真实设备，并保持同步。

为什么有些网站无法加载？+

有些网站禁止被嵌入到其他页面中显示。Mobile View 会提示你，并可在新标签页中打开。

修复提示会上传我的代码吗？+

不会。提示在你的电脑上生成，供你粘贴到自己的编程工具中。
