常見問題。

免費嗎？+

是的。採用 MIT 授權免費開源，不需要帳號。

支援 localhost 嗎？+

支援。在 Chrome 中開啟本機頁面，再開啟 Mobile View 即可。任何資料都不會離開你的電腦。

和 DevTools 的裝置模式有什麼不同？+

DevTools 一次只顯示一個檢視區。Mobile View 並排顯示四台真實裝置，而且保持同步。

為什麼有些網站無法載入？+

有些網站禁止被嵌入其他頁面中顯示。Mobile View 會告訴你，並可改在新分頁中開啟。

修正提示會上傳我的程式碼嗎？+

不會。提示在你的電腦上產生，讓你貼到自己的程式開發工具中。
